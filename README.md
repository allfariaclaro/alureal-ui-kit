# Alureal UI Kit

Base reutilizável para sites, landing pages e produtos digitais da Alureal.

## Inclui
- tokens de cor, tipografia, espaçamento, radius, sombra e movimento;
- dark/light por `data-theme`;
- botão, card, badge, input, select, textarea, modal, toast, navbar, hero e pricing;
- estados de foco e acessibilidade;
- responsividade sem framework;
- respeito a `prefers-reduced-motion`.

## Uso
Abra `index.html` no navegador ou rode `npm run serve`.

## Estrutura
- `src/tokens.css`: design tokens;
- `src/components.css`: componentes;
- `src/app.js`: tema, modal e toast;
- `index.html`: catálogo vivo dos componentes.
