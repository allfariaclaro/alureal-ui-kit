# Princípios de UI Alureal

1. Clareza antes de decoração.
2. Movimento deve explicar hierarquia, não competir com conteúdo.
3. Mobile é condição de projeto, não adaptação tardia.
4. Estados de foco, hover, loading, erro e sucesso fazem parte do componente.
5. Tokens centralizam decisões repetidas.
6. Contraste e redução de movimento são requisitos padrão.
7. Cada projeto pode ter direção de arte própria sem quebrar a infraestrutura base.
